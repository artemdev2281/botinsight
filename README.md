# BotInsight

Платформа развития чат-ботов на основе анализа диалогов

# Суть продукта

**BotInsight** - платформа для анализа данных о взаимодействии пользователей с чат-ботами. Система позволяет загружать логи диалогов, исследовать структуру пользовательских обращений, находить необработанные запросы и проблемные сценарии, отслеживать ключевые показатели работы чат-бота и формировать backlog улучшений.

Основная задача продукта - преобразовать данные о взаимодействиях пользователей с чат-ботом в понятную продуктовую аналитику

## Назначение

Команды, развивающие чат-ботов, накапливают большое количество данных о диалогах. Из сырых данных можно извлекать информацию для принятия продуктовых решений. Для этого данные необходимо структурировать, обрабатывать и интерпретировать.

BotInsight позволяет:

- изучать обращения пользователей к чат-боту;
- находить запросы, которые бот не смог корректно обработать;
- выявлять проблемные сценарии и этапы диалога;
- отслеживать основные показатели работы чат-бота;
- фиксировать найденные проблемы в backlog улучшений.

## Концепция продукта

```text
Данные чат-бота

      ↓
```

## Пользовательские сценарии

### Основные сценарии

- Создание проекта для анализируемого чат-бота.
- Загрузка логов диалогов в формате CSV или JSON.
- Просмотр основных показателей проекта.
- Исследование структуры и динамики пользовательских обращений.
- Анализ fallback-запросов.
- Оценка успешности пользовательских сценариев.
- Поиск проблемных этапов диалога.
- Создание задач на улучшение продукта.
- Управление backlog'ом.

### Примеры сквозных сценариев

**Поиск причин fallback:** 
Изучение Dashboard → Обнаружение высокого fallback rate → Переход в раздел fallback-запросов → Изучение проблемных сообщений → Создание задачи в backlog.

**Поиск проблемного сценария:** 
Изучение Dashboard → Обнаружение снижения completion rate → Переход в раздел сценариев → Поиск проблемного этапа → Изучение диалогов → Создание задачи на изменение сценария.

**Анализ изменений в обращениях:** 
Изучение обращений → Обнаружение роста определённого intent'а → Анализ сообщений → Оценка необходимости улучшения → Создание задачи в backlog.

## Функциональные модули

### Проекты

Создание и управление анализируемыми чат-ботами. Один пользователь может иметь несколько независимых проектов.

### Импорт данных

Загрузка логов чат-бота в фиксированном формате CSV или JSON. 

### Dashboard

Сводное представление основных показателей проекта.

### Анализ обращений

Исследование пользовательских запросов:

- intents;
- количество и динамика обращений;
- confidence;
- fallback rate.

### Анализ fallback-запросов

Исследование сообщений, которые чат-бот не смог корректно обработать:

- fallback rate;
- динамика;
- исходные сообщения;
- intents и confidence;
- связанные сценарии.

### Анализ сценариев

Оценка прохождения пользовательских сценариев:

- completion rate;
- abandoned;
- fallback;
- перевод на оператора;
- проблемные этапы сценария.

### Backlog улучшений

Список задач на улучшение продукта.

Основные атрибуты:

- название;
- описание;
- приоритет;
- статус;
- источник проблемы.

Статусы: `Открыта`, `В работе`, `Выполнена`.

### Авторизация

Регистрация, вход в систему и доступ пользователя к своим проектам.
